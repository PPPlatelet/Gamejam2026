# 视觉小说框架第一轮

基线为 dev 9a3efa0。用户已确认开工，剧情由团队另行撰写，试玩仅使用中性功能标签。

- 主菜单进入独立试玩，战斗 V 键兼容旧剧本，退出恢复原场景与暂停状态。
- JSON 沿用 title、pages、speaker、text 或 lines，增加稳定页 ID、背景、立绘和有向选择。
- 验收手动阅读、快显、连续自动播放、选择时停等、走过的对白与选择回看。
- 单槽仅保存所读文件剧本的页位置和路径历史，重启后可恢复；损坏或不匹配时给出反馈。
- 使用 Godot 4.7.2 检查旧三页回归、两条示例路线、暂停恢复和存档恢复。正式剧情交由文案接入。

## 验收记录

Godot 4.7.2 已导入工程。旧入口 21 项自检通过。新试玩的 14 项检查在 Windows 导出预设生成的 PCK 中通过，覆盖两个选择、已读日志、旧存档覆盖及恢复、坏档、结尾和暂停恢复。游戏内存档仅记录小说进度。Windows 独立 EXE 的验收待发布阶段完成。

## 第二轮 · 阅读控制与标题系统

用户确认沿当前路线导航，分支停等，返回上一个选项可以重选。局内提供手动与快速存读档、设置与主音量、前后场景和选项、快退、上一句、历史、自动、快进、流程图、隐藏 HUD 和返回标题。标题提供新游戏、读档、继续、流程图、设置和退出接口。保留战斗入口，沿用已有测试文字。验收两条分支与汇合、模式暂停、跨进程存档、无存档和损坏状态、旧档兼容、导出包与入口回归。

第二轮验收完成。Godot 4.7.2 的 Windows 预设 PCK 通过阅读和标题流程自检、独立新进程读档与设置恢复、旧入口的 21 项回归。额外通过鼠标事件验证主菜单 → VN 标题 → 新游戏 → 阅读导航 → 遇分支停等 → 返回标题 → 退出进程。仓库本地 CI 通过。
