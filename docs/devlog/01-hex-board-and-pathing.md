# 开发日志 1：把塔防塞进六边形格子

> 项目：雾海哨线（暂定名）· Gamejam2026
> 日期：2026-11-22

## 为什么是六边形

一开始就确定要六边形棋盘：斜向的距离比方格更均匀，敌人绕路时不会有"走斜线占便宜"的问题。实现上用的是 **pointy-top + odd-r 偏移坐标**（`scripts/hex_board.gd`）：

- 一格的外接圆半径记为 1 个单位，宽 `sqrt(3)`、行间距 1.5，换算成像素只乘一个 `radius`；
- 逻辑坐标以棋盘中心为原点，鼠标坐标反向换算成格子时，先减掉棋盘尺寸的一半，再补上 `HEX_WIDTH / 2` 和 `1.0` 的偏移——这两个偏移是早期"点哪都偏一格"的根源，后来用"全盘 180 格往返测试"才确认修好。

## 寻路与"不要都走同一条线"

敌人逐格移动，用 A*（启发式是立方坐标距离）算最短路径，再按格子中心连成折线平滑前进。第一版跑起来很整齐：所有敌人从固定出生点、沿同一条线排队走过来，看着像一队蚂蚁。

于是加了三层随机（`scripts/game.gd` + `scripts/enemy.gd`）：

1. **出生点随机**：每次按 L 出怪，从所有出生点里随机挑一个，不再轮流。
2. **随机绕路点**：约 45% 的敌人会在 2～7 格内随机选一个空格子作为中途点，先绕过去再回基地；中途点会被记录在敌人身上，放船/拆船重新寻路时如果它还在前面就继续绕，已经路过或被占住就自动放弃。
3. **同长路随机 + 走线抖动**：A* 在 f 值相同的节点里随机挑，避免唯一解；每个敌人的整条路线再叠加 ±0.24 格的左右偏移，几个敌人从同一格经过时也不会完全重叠。

## 手动出怪

最初是定时自动刷怪，测试时节奏很死。改成按 **L** 手动出一艘，配合随机出生点和绕路，同一套数值下每局的压力曲线都不一样，也方便录演示视频时控制节奏。
