# 雾海哨线（暂定名）· Gamejam2026

一个六边形格子上的海战塔防：**F5 是船坞（基地）**，敌舰从雾里出现，沿最短路径逐格逼近；你在格子上放下三种船，用减速、点杀和范围火力把她们拦在海上。

- 引擎：Godot 4.7.2 stable，GL Compatibility
- 平台：Windows 10/11（开发环境）
- 素材与 AI 声明：[CREDITS.md](CREDITS.md)

## 从源码运行

1. 安装 Godot **4.7.2**（标准版即可，无需 .NET）。
2. 克隆仓库后，用 Godot 导入根目录的 `project.godot`。
3. 按 **F5** 运行，主场景是 `scenes/opening.tscn`。

启动流程：开场（`opening.tscn`）→ 主菜单（`main_menu.tscn`）→ 游戏（`game.tscn`）。进入关卡时会播卷轴展开动画（`scenes/level_intro.tscn`，约 3.4 秒，点击/空格可跳过）：手绘水墨卷轴从左往右铺开（展开本身 1.4 秒），亮纸透出带网格的地图，播完才开始计时；网格在开场结束后再保留两秒。

## 操作说明

| 操作 | 效果 |
|---|---|
| 按住左侧三个按钮之一，拖到格子上松手 | 放置对应船（哨船 15 / 火箭船 25 / 炮船 35 粮草），船从船坞滑到目标格 |
| 左键点己方船，再点目标格 | 移动该船，每格消耗 2 指挥点；选中会亮出网格，移动中再点它一次可改目标 |
| **L** | 出一艘敌舰（出生点随机、路线带随机绕行） |
| **J** | 打开/关闭状态窗口；**按住 J 再按 1–4** 召唤指定敌人 |
| **J + 1 / 2 / 3 / 4** | 召唤 倭寇小船 / 倭刀船 / 冲锋船 / 炸弹船 |
| **H** | 显示/隐藏格子编号 |
| **P** | 显示/隐藏敌人路线 |
| **V** | 打开视觉小说剧情 |
| **R** | 重开本局 |
| **F11** | 全屏切换 |
| **Esc** | 取消放置 → 关闭状态窗口 → 返回主菜单 |

## 玩法要点

- **一局 15 分钟**：撑到 15:00 且基地还在就判胜利；基地血量归零则失败。
- **资源**：指挥点每秒 +1（上限 50，开局 20）；粮草每 2.75 秒 +1（上限 200，开局 50）。
- **哨船**：不攻击，范围内敌人移速 ×0.55，血量最高，适合在前排扛伤害。
- **火箭船**：单体、0.5 秒一发，命中后燃烧 3 秒，适合点杀。
- **炮船**：1.7 秒一发，落点范围伤害，12% 概率对主目标一击必杀。
- **我方移动**：船也是逐格移动——走一格停 0.4 秒（`STEP_PAUSE`），从基地出发和手动移动都一样；移动途中照样开火，也能被点中改目标。
- **剧情与出兵分开**：台词在 `scripts/story_lines.gd`（触发 / 位置 / 内容），出兵在 `scripts/spawn_waves.gd`（时间 / 出生格 / 兵种数量），两边各改各的、互不影响；每波用 `cell` 指定从哪个格子出怪，没写就用 `Game` 的 `spawn_cell`；L / J+数字 仍可手动测试。
- **字幕位置**：每条台词可以用 `where` 选预设位置（顶部 / 中间 / 底部 / 左上 / 右侧），也可以用 `at: [x, y]`（屏幕比例 0~1）精确摆放。
- **放置提示**：只有在放置单位时才会出现格子高亮——目标格用青色六边形描边（`assets/ui/cell_marker.png`），不能放时描边变红；平时鼠标不显示任何格子。
- **放船按钮**：左侧三个按钮用水墨按键图（`assets/ui/ink_button.png`）做底，文字为白色宋体。
- **字体**：全局 UI 用 Noto Serif SC（思源宋体，OFL 1.1，`fonts/NotoSerifSC-VF.ttf`）；剧情字幕保留原来的手写体（`fonts/ZhiMangXing.ttf`），黑字；按钮与关卡标题白字。
- **敌人**：分四种——
  - **倭寇小船**：40 血、1 格/秒，普通的近战杂兵；
  - **倭刀船**：移动快（1.5 格/秒），近战命中会**眩晕**我方单位并附加持续伤害；
  - **冲锋船**：不攻击，给附近敌人加 30% 移速和攻速；
  - **炸弹船**：血厚（90）跑得快，碰到我方单位直接**自爆**，范围伤害并点燃。
  按 L 随机出怪（小船最常见），按住 J 再按 1–4 可指定类型；每有一艘抵达基地，基地 -1 血，归零即失败。
- **敌人移动**：逐格前进——走到一格中心后停 0.5 秒（`PAUSE_PER_CELL`），再走下一格。

## 一局流程（15 分钟）

剧本在 `scripts/story_lines.gd`，出兵表在 `scripts/spawn_waves.gd`（两边独立，时间对齐即可）；每波可以用 `cell` 指定自己的出生格（下面按 A1 编号写）：

| 时间 | 波次 | 出生格 | 出兵（小船 / 刀船 / 冲锋船 / 炸弹船） |
|---|---|---|---|
| 0:10 | 雾起 | R4 | 4 / 0 / 0 / 0 |
| 1:10 | 试探 | R4 | 4 / 0 / 0 / 0 |
| 2:20 | 刀船 | R4 | 4 / 2 / 0 / 0 |
| 3:30 | 浅滩 | R6 | 6 / 2 / 0 / 0 |
| 4:40 | 刀船增多 | R6 | 4 / 3 / 0 / 0 |
| 5:50 | 冲锋船 | R4 | 4 / 3 / 2 / 0 |
| 7:00 | 号旗倒 | R6 | 6 / 3 / 2 / 0 |
| 8:10 | 炸弹船 | K11 | 6 / 3 / 0 / 2 |
| 9:20 | 列队 | K11 | 7 / 4 / 0 / 2 |
| 10:30 | 雾厚 | R9 | 7 / 4 / 2 / 2 |
| 11:50 | 总攻 | K11 | 7 / 4 / 0 / 3 |
| 13:10 | 三面 | R9 | 7 / 4 / 2 / 2 |
| 14:20 | 最后一批 | K11 | 8 / 6 / 2 / 3 |
| 14:50 | 收尾 | — | 只有台词 |
| 15:00 | 胜利 | — | 弹出「守住了」 |

难度旋钮：`Game` 检查器的 `wave_scale`（默认 1.0，调大更难）。按自动放船的模拟，满流程约 136 艘敌船、132 击杀、2 艘漏过，基地剩 18/20。

## 构建 Windows 发行版

已安装 Godot 4.7.2 导出模板时，在仓库根目录执行：

```powershell
godot --headless --export-release "Windows Desktop" "build/Gamejam2026.exe"
```

产物为同目录下的 `Gamejam2026.exe` 与 `Gamejam2026.pck`，运行时双击 exe 即可；**pck 必须和 exe 放在一起**。构建产物不入库（见 `.gitignore`），正式发行版由 PPPlatelet 在阶段发布时通过 GitHub Releases 提供。

## 目录结构

```
assets/          地图底图、船图（ships/）、水墨特效（fx/）、按钮素材
docs/            开发说明、截图、开发者日志
fonts/           字体：Noto Serif SC（界面）与 ZhiMangXing（字幕）
opening/         开场插画
scenes/          场景（游戏、棋盘、实体、菜单、VN、字幕层）
scripts/         玩法脚本（棋盘、单位、敌人、游戏流程、剧情数据）
shaders/         暗角等着色器
tools/           占位素材生成、测试与预览脚本
vn/              视觉小说剧情数据
```
