# 开发日志 3：用字幕讲故事，以及一份能交出去的素材声明

> 项目：雾海哨线（暂定名）· Gamejam2026
> 日期：2026-11-22

## 为什么不做整屏剧情

视觉小说（V 键）能讲完整段落，但塔防的节奏是连续的：玩家在放船、在等粮草、在看敌人绕路。中途弹一个全屏对话会把操作打断。所以主线之外的氛围文字做成了**游戏内字幕**：不挡操作、淡入淡出、一次一条。

## 剧本是数据，不是代码

所有文案放在 `scripts/story_lines.gd` 的一个数组里，每条只回答四个问题：

```gdscript
{
    "id": "first_enemy",                          # 唯一名字，改名会重新播
    "when": {"type": "spawn", "count": 1},        # 什么情况触发
    "where": "bottom",                            # 出现在哪
    "text": "第一艘敌舰从雾里探出头来——……",       # 内容
    "seconds": 6.0,
}
```

`when` 支持开局、计时、累计出怪、累计击杀、敌人抵达、基地血量、场上船数、粮草、单位被摧毁和失败；`where` 支持顶部、正中、底部、左上、右侧。加台词只改这一个文件，不用碰场景。

## 字幕层：没有底板，只有字

`scripts/story_overlay.gd` 是一个铺满屏幕的 Control：自己按字符宽度折行、按 `where` 定位、自己画文字，淡入 0.3 秒、淡出 0.6 秒；同时触发多条时排队依次播。字幕**没有背景块**，黑字直接压在石面地图上，字体用的是 Zhi Mang Xing（SIL OFL 1.1），随仓库附上了 `fonts/OFL.txt`。

## 素材与 AI 声明

比赛要求"如实说明工具、用途、生成内容与人工修改情况"，所以仓库里有一份 [CREDITS.md](../../CREDITS.md)：第三方素材（字体 OFL、Godot 图标 CC BY 4.0）、团队自绘素材、AI 生成内容（代码、场景、占位美术脚本、开场插画临时版、文案初稿）以及人工完成的部分，逐项列清楚。开场插画目前是 AI 临时版，替换成自绘后要同步更新声明——这一点也写进了文档。

## 协作方式

开发走 GitHub 的 PR 流程：`dev` 是集成分支，任务分支按 `feature/成员/任务` 命名，PR 里附改动说明和验证记录，由非作者审核后 Squash and merge。素材启用 Git LFS，`.gitattributes` 的规则不允许随手改。
